TPJ | S8 — Website tuyển dụng + gửi hồ sơ về Telegram

1. Cài Node.js LTS.
2. Copy .env.example thành .env.
3. Mở .env và điền BOT TOKEN của BotFather. Không chia sẻ token.
4. TELEGRAM_CHAT_ID=-1004341368809
5. Mở CMD tại thư mục website và chạy: node server.js
6. Truy cập: http://localhost:8088

Form ứng viên gửi về group Telegram thông qua server, token không nằm trong frontend.
